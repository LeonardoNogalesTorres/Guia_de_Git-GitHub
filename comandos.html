Diccionario de Comandos Git

Referencia técnica con combinaciones, banderas y casos de uso prácticos.

← Volver al Inicio

⚙️ 1. Configuración e Identidad

Establecer usuario y correo global

git config --global user.name "Tu Nombre" git config --global user.email "tu@email.com" # Identifica la autoría de tus commits en todo el sistema.

Listar y editar configuraciones

git config --list # Muestra todas las variables de configuración activas. git config --global core.editor "code --wait" # Establece VS Code como editor predeterminado de Git. git config --global init.defaultBranch main # Configura 'main' como la rama por defecto para nuevos repositorios.

🚀 2. Creación y Clonado

Inicializar repositorio local

git init # Convierte el directorio actual en un repositorio Git (.git).

Clonar repositorios remotamente

git clone https://github.com/usuario/repo.git # Descarga una copia local del repositorio remoto. git clone -b rama-especifica https://github.com/usuario/repo.git # Clona directamente una rama específica. git clone --depth 1 https://github.com/usuario/repo.git # Clona solo el último commit (descarga ligera y rápida).

📝 3. Estado, Cambios y Commits

Ver estado de los archivos

git status # Muestra archivos modificados, en staging o no rastreados. git status -s # Muestra el estado en formato corto/resumido.

Añadir al área de preparación (Staging)

git add nombre-archivo.txt # Añade un archivo específico. git add . # Añade todos los cambios del directorio actual. git add -p # Modo interactivo: permite añadir fragmentos específicos de código.

Confirmar cambios (Commit)

git commit -m "Mensaje descriptivo" # Guarda una foto del área de preparación con un mensaje. git commit -am "Añade y confirma en un solo paso" # Para archivos ya rastreados (salta 'git add'). git commit --amend -m "Nuevo mensaje corregido" # Sobrescribe el último commit realizado. git commit --amend --no-edit # Añade cambios olvidados al último commit sin alterar su mensaje.

🌿 4. Manejo de Ramas (Branches)

Listar ramas

git branch # Lista las ramas locales. git branch -a # Lista ramas locales y remotas. git branch -v # Muestra el último commit de cada rama.

Crear, renombrar y cambiar de rama

git branch nueva-rama # Crea una nueva rama. git switch nueva-rama # Cambia a la rama especificada (Sustituye a 'git checkout'). git switch -c nueva-rama # Crea y cambia a la nueva rama en un solo paso. git branch -m nombre-viejo nombre-nuevo # Renombra una rama existente.

Fusionar e Integrar (Merge & Rebase)

git merge nombre-rama # Fusiona la rama especificada dentro de la rama actual. git merge --no-ff nombre-rama # Fuerza la creación de un commit de fusión explícito. git rebase main # Reorganiza los commits de la rama actual sobre la punta de 'main'. git cherry-pick ID_COMMIT # Aplica un commit específico de otra rama a la rama actual.

Eliminar ramas

git branch -d nombre-rama # Elimina la rama de forma segura (solo si ya fue fusionada). git branch -D nombre-rama # Fuerza la eliminación de la rama sin importar su estado.

🌐 5. Servidores Remotos (GitHub)

Gestionar conexiones remotas

git remote -v # Lista las URLs de los repositorios remotos vinculados. git remote add origin https://github.com/usuario/repo.git # Añade una nueva vinculación remota llamada 'origin'. git remote set-url origin https://github.com/usuario/nuevo-repo.git # Cambia la URL del remoto existente.

Descargar y subir datos

git fetch origin # Descarga la información del remoto sin modificar tus archivos locales. git pull origin main # Descarga y fusiona los cambios remotos en tu rama actual. git pull --rebase origin main # Descarga y reordena tus avances sobre la versión más reciente del servidor. git push -u origin main # Sube tus cambios y establece el rastreo por defecto. git push origin --delete nombre-rama # Elimina una rama en el servidor remoto de GitHub.

📜 6. Historial y Diferencias

Historial de confirmaciones (Log)

git log # Muestra el historial completo de commits. git log --oneline --graph --all # Muestra el historial simplificado en una línea con diagrama de ramas. git log -n 5 # Muestra únicamente los últimos 5 commits. git log --author="Nombre" # Filtra el historial por el autor de los cambios.

Comparación de cambios (Diff)

git diff # Compara el directorio de trabajo actual con el área de staging. git diff --staged # Compara el área de staging con el último commit. git diff rama1..rama2 # Muestra las diferencias entre dos ramas distintas. git blame archivo.js # Muestra quién modificó cada línea de un archivo y en qué commit.

⏪ 7. Cancelación y Corrección de Errores

Descartar y restaurar cambios

git restore archivo.html # Restaura un archivo al estado del último commit (borra cambios locales). git restore --staged archivo.html # Remueve el archivo del área de staging pero conserva tus modificaciones.

Resetear historial

git reset HEAD~1 # Deshace el último commit manteniendo tus cambios en el código. git reset --soft HEAD~1 # Deshace el último commit devolviendo los cambios al área de staging. git reset --hard HEAD~1 # Peligro: Deshace el último commit y elimina todos los cambios de código. git revert ID_COMMIT # Crea un nuevo commit que deshace exactamente lo hecho en un commit anterior.

📦 8. Guardado Temporal, Limpieza y Registros

Guardado temporal (Stash)

git stash # Guarda temporalmente cambios no confirmados para limpiar el espacio de trabajo. git stash save "Mensaje opcional" # Guarda con una descripción personalizada. git stash list # Muestra la lista de todos los guardados temporales. git stash pop # Aplica el último stash y lo elimina de la lista. git stash drop # Elimina el último stash guardado.

Limpieza de archivos sin rastrear

git clean -n # Muestra qué archivos no rastreados se borrarían sin eliminarlos aún. git clean -fd # Elimina de forma permanente archivos y carpetas no rastreados.

Registro de acciones avanzadas (Reflog)

git reflog # Muestra el historial completo de acciones del HEAD. Útil para recuperar commits o ramas borradas por error.
