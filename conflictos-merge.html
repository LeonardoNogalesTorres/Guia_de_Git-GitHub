⚔️ Guía de Resolución de Conflictos (Merge Conflicts)

Aprende por qué ocurren, cómo identificarlos en VS Code y los pasos exactos para solucionarlos sin perder código.

← Volver al Inicio
Concepto Sencillo

¿Por qué ocurre un Conflicto de Fusión?

Imagina que tú y un compañero abren el mismo menú de restaurante en la misma línea (el precio de la hamburguesa):

  • Tú en tu rama cambias el precio a $10.
  • Tu compañero en su rama cambia el mismo precio a $12.

Al intentar unir ambas ramas con git merge, Git no sabe cuál precio es el correcto y detiene todo diciendo: "Decide tú cuál precio se queda".

Anatomía

¿Cómo se ve el conflicto dentro del archivo?

Git encierra la línea en conflicto con marcas especiales para mostrarte exactamente qué cambió en cada lado:

<<<<<<< HEAD (Lo que tienes en TU rama actual 'main') <li class="menu-item">Hamburguesa Clasica - Precio: $10</li> ======= (Línea que separa ambas versiones) <li class="menu-item">Hamburguesa Clasica - Precio: $12</li> >>>>>>> feature/actualizar-precios (Lo que viene de la OTRA rama)

Guía rápida de marcas:

  • <<<<<<< HEAD: Inicio de TU versión local.
  • =======: Divisoria central.
  • >>>>>>> nombre-rama: Fin de la versión que proviene de la otra rama.
Paso 1

Identificar los archivos con problemas

Ejecuta este comando para ver qué archivos tienen choques pendientes:

git status # Verás el archivo 'menu.html' listado en rojo bajo "Unmerged paths".
Paso 2

Resolver el conflicto en VS Code (Ejemplo Práctico)

Abre menu.html en Visual Studio Code. Arriba de las marcas verás 4 botones interactivos de clic rápido:

1. Accept Current Change (Aceptar tu cambio)

Te quedas con tu precio ($10). El resultado final automático será:

<li class="menu-item">Hamburguesa Clasica - Precio: $10</li>

2. Accept Incoming Change (Aceptar el cambio entrante)

Te quedas con el precio de la otra rama ($12). El resultado final automático será:

<li class="menu-item">Hamburguesa Clasica - Precio: $12</li>

3. Edición Manual (La mejor opción si acuerdan una oferta)

Borras manualmente las marcas de Git (<<<, ===, >>>) y dejas el texto acordado, por ejemplo, un precio intermedio ($11):

<li class="menu-item">Hamburguesa Clasica - Oferta: $11</li>
Paso 3

Guardar y finalizar la Fusión

Una vez resuelto el texto y borradas las marcas de Git en el archivo, guarda el archivo en VS Code y ejecuta:

git add menu.html # Le confirmas a Git que ya solucionaste el conflicto de este archivo. git commit -m "Fix: Se define el precio final de la hamburguesa en $11" # Cierras el proceso de fusión registrando el cambio definitivo. git push origin main # Subes la solución limpia a GitHub.
⚠️ Botón de Pánico

¿Quieres cancelar y volver atrás?

Si te confundiste editando y prefieres deshacer el intento de merge para empezar de nuevo sin romper nada:

git merge --abort # Cancela el merge y deja tus archivos limpios tal como estaban antes del choque.
