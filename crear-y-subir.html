De Local a GitHub desde Cero

Pasos para iniciar un proyecto en tu computadora y publicarlo por primera vez en GitHub.

← Volver al Inicio
Paso 1

Crear la carpeta y tus archivos locales

Crea el directorio de trabajo en tu equipo y ábrelo en Visual Studio Code.

  • Abre VS Code y ve a File > Open Folder para seleccionar tu carpeta.
  • Crea tus archivos iniciales (por ejemplo: index.html, styles.css, etc.).
  • Opcional: Crea un archivo llamado .gitignore para especificar archivos que no quieras subir (como carpetas de configuración o claves).
Paso 2

Inicializar Git en la carpeta

Abre la terminal integrada en VS Code (Ctrl + ~ o Terminal > New Terminal) y ejecuta el comando para activar el control de versiones en esa carpeta:

git init # Crea la carpeta oculta .git y convierte la carpeta en un repositorio local.
Paso 3

Registrar tu primer Commit local

Prepara todos tus archivos recién creados y guarda una instantánea de tu código antes de conectar con la nube.

git add . # Prepara todos los archivos recién creados. git commit -m "Primer commit: Estructura inicial del proyecto" # Registra el estado inicial en el historial local.
Paso 4

Crear el Repositorio en la web de GitHub

Abre tu navegador y sigue estos pasos en tu cuenta de GitHub:

  1. Ingresa a github.com e inicia sesión.
  2. Haz clic en el botón verde "New" o en el icono "+" (arriba a la derecha) y selecciona New repository.
  3. Asigna un nombre a tu repositorio (ejemplo: mi-primer-sitio).
  4. IMPORTANTE: Deja desmarcadas las casillas de Add a README file, Add .gitignore y Choose a license (ya que el proyecto lo creaste localmente).
  5. Haz clic en el botón "Create repository".
Paso 5

Vincular y subir tu código por primera vez

Copia y ejecuta los siguientes comandos en la terminal de VS Code para conectar tu carpeta con el repositorio vacío que acabas de crear en GitHub:

git branch -M main # Renombra la rama predeterminada a 'main'. git remote add origin https://github.com/tu-usuario/tu-repositorio.git # Enlaza la carpeta local con la URL de tu repositorio remoto en GitHub. git push -u origin main # Sube tu primer commit y guarda la vinculación predeterminada.
