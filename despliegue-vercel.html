🌐 Publicar Tu Web Gratis en Vercel

Guía opcional: Convierte tu repositorio de GitHub en una página web accesible desde cualquier lugar.

← Volver al Inicio
Requisito Previo

Tener tu código subido a GitHub

Antes de comenzar, asegúrate de haber subido la carpeta de tu proyecto a un repositorio en GitHub (sea público o privado).

Paso 1

Iniciar sesión en Vercel con GitHub

Ingresa a la página oficial de Vercel y vincula tu cuenta:

  1. Entra a vercel.com.
  2. Haz clic en el botón "Sign Up" o "Log In" (arriba a la derecha).
  3. Selecciona la opción "Continue with GitHub" e inicia sesión con tus credenciales.
Paso 2

Importar tu Repositorio

Una vez dentro del panel principal (Dashboard) de Vercel:

  1. Haz clic en el botón azul "Add New..." y selecciona "Project".
  2. Aparecerá un listado con todos tus repositorios de GitHub. Busca el nombre de tu proyecto.
  3. Haz clic en el botón "Import" junto a tu repositorio.
Paso 3

Configurar y Desplegar (Deploy)

Vercel detecta automáticamente que se trata de un proyecto web:

  1. Project Name: Puedes modificar el nombre si deseas personalizar la dirección URL.
  2. Framework Preset: Para proyectos de HTML/CSS puro, déjalo en la opción predeterminada o "Other".
  3. Haz clic en el botón azul "Deploy".
Paso 4

¡Tu página web está en vivo!

En pocos segundos la plataforma compilará tus archivos y mostrará una pantalla de felicitación:

  • Haz clic en la imagen de vista previa o en el botón "Visit".
  • Tu sitio ya estará activo bajo un dominio gratuito como: https://tu-proyecto.vercel.app.
⚡ Ventaja Principal

Despliegue Automático (CI/CD)

Cada vez que hagas un git push origin main desde VS Code a GitHub, Vercel actualizará tu página pública en tiempo real de forma automática en cuestión de segundos, sin necesidad de realizar ningún paso manual.
