Guía de Trabajo Colaborativo

Aprende el ciclo de trabajo desde clonar un proyecto hasta actualizar cambios.

← Volver al Inicio
Paso 1

Clonar un Repositorio (`git clone`)

Descarga una copia exacta de un proyecto existente en GitHub a tu computadora local.

git clone https://github.com/usuario/nombre-del-proyecto.git cd nombre-del-proyecto # Entras a la carpeta del proyecto que acabas de clonar.
Paso 2

Realizar Cambios y Guardarlos Localmente

Edita tus archivos en VS Code y prepara los avances para el registro.

git status # Revisa qué archivos modificaste o creaste. git add . # Añade todos los cambios al área de preparación. git commit -m "Se añade la interfaz de navegación" # Registra tus avances localmente.
Paso 3

Actualizar tu repositorio local (`git pull`)

¡Importante! Antes de subir tus cambios, descarga siempre lo que otros hayan subido al servidor para evitar conflictos.

git pull origin main # Trae e integra los últimos avances guardados en GitHub.
Paso 4

Subir tus Avances a GitHub (`git push`)

Envía los commits que hiciste localmente hacia el repositorio remoto.

git push origin main # Envía tus avances a la rama principal de GitHub.
