1. Configuración Inicial

Lo primero que debes hacer tras instalar Git es identificar tu usuario y correo:

git config --global user.name "Tu Nombre" git config --global user.email "tu@email.com"

2. Flujo de Trabajo Básico

Pasos cotidianos para guardar cambios localmente:

Inicializar un proyecto

git init

Guardar cambios (Staging & Commit)

git add . # Prepara todos los archivos modificados git commit -m "Mensaje descriptivo del cambio" # Guarda una foto del proyecto

Verificar el estado

git status

3. Manejo de Ramas (Branches)

Las ramas te permiten trabajar en nuevas funciones sin alterar el código principal (main).

Acción Comando
Crear una nueva rama git branch nombre-rama
Cambiar a una rama git switch nombre-rama
Crear y cambiar a la vez git checkout -b nombre-rama
Fusionar rama actual con otra git merge nombre-rama
Eliminar una rama git branch -d nombre-rama

4. Conectar y Subir a GitHub

Para sincronizar tu repositorio local con la nube:

git remote add origin https://github.com/usuario/repositorio.git # Vincula el repositorio remoto git branch -M main # Asegura que la rama principal se llame main git push -u origin main # Sube tus cambios por primera vez
